# The Tower That Would Not Fall

An interactive, single-page introduction to the **Yingxian Wooden Pagoda** (應縣木塔 / 佛宫寺释迦塔), built in 1056 during the Liao dynasty in Shanxi, China.

**Course:** Chinese Culture & International Communication · Zhejiang University  
**Student:** Wu Junru (吴俊儒)

## What is on the page

- A procedurally generated **3D pagoda** (Three.js) — drag to rotate, scroll to zoom, click a level
- An **exploded structure viewer** with a "pull the tower apart" control
- An interactive **dougong bracket set** with all six pieces explained on the drawing
- Two hands-on games: **assemble the bracket** and **stack the pagoda**
- **Eight flip cards** of surprising facts
- A **six-question quiz** with explanations
- A short **English-language guide** for talking about the building

Everything is a single `index.html` file: no build step, no external requests, no images or plugins. Open it directly or host it anywhere.
